# Hermes Resident-Once Runtime

Phase: 7B
Status: validated for governed manual dry-run operation

## Purpose

The resident-once runtime is the minimal launchd-safe runtime used to run Hermes' governed local resident-shaped shell once and then exit.

It does not enable command execution, live Hermes inference, adapter auto-start, Desktop launch, external integrations, credentials, `RunAtLoad=true`, or `KeepAlive=true`.

## Runtime Contents

The runtime contains only the governed resident-once script, the local `services/hermes_safety` modules needed for audit, file-zone, and command-policy classification, a runtime inbox, a runtime outbox, control files, and local logs.

The runtime is intentionally separate from the `Documents` repo path because macOS launchd denied execution from the repo path during Phase 7A.

The wrapper exports:

```text
HERMES_CODE_ROOT=<runtime path>
HERMES_REPO_ROOT=<runtime path>
HERMES_COMMAND_EXECUTION_ENABLED=false
HERMES_EXTERNAL_INTEGRATIONS_ENABLED=false
```

The LaunchAgent uses:

```text
Label=com.msr.hermes.resident-once
RunAtLoad=false
KeepAlive=false
ProgramArguments=/Users/michaelrinebold/.local/bin/msr-hermes-resident-once
```

## Repository References

The runtime does not execute from the repo and does not require launchd to access the repo path. It is regenerated from repo source when the resident-once script or safety modules change.

The repo remains the source of truth for:

- `scripts/hermes_resident_once.sh`
- `services/hermes_safety/`
- docs and tests

## Regeneration

The runtime can be safely regenerated by copying only:

- `scripts/hermes_resident_once.sh`
- `services/hermes_safety/__init__.py`
- `services/hermes_safety/audit_log.py`
- `services/hermes_safety/command_policy.py`
- `services/hermes_safety/file_zones.py`
- `services/hermes_safety/policy_result.py`

Do not copy credentials, `.env` files, arbitrary repo files, Desktop artifacts, or external integration config into the runtime.
